# Review Checklist

Every checklist item needs an owner before merge.

## Correctness

- The change does what the description says it does.
- Tests cover the new behavior.
- No debug logging or commented-out code is left behind.

## Readability

- Names are clear and consistent with the surrounding code.
- Public interfaces have up-to-date documentation.

## Safety

- No secrets or credentials are committed.
- The change can be rolled back without manual surgery.

## Ownership

- Every unresolved conversation has been answered.
- The checklist above has been walked through item by item.
